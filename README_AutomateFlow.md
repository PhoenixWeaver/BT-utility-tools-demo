# ⚙️ Customer Experience Request Management Automation Platform — README

**Microsoft Power Automate | Power Apps | Microsoft Lists | Outlook | Microsoft 365**

---

## 🚀 Overview

Designed and implemented a comprehensive case management and workflow automation solution to streamline customer service operations across multiple request types, countries, languages, and processing teams. This centralized platform automates request intake, case classification, workload assignment, status tracking, and stakeholder communications, significantly reducing manual effort and improving operational visibility.

---

## ✨ Key Features & Contributions

*   **Multi-Scenario Workflow Engine:** Designed a robust engine capable of processing various request types including AWB Label Requests, Unwanted Shipments, Unreached Shipments, Clearance Requests, Picked/Closed Cases, and other operational exceptions.

*   **Dynamic Case Routing:** Developed logic using Power Automate's `Switch` and `Condition` controls to automatically assign cases based on request category, language requirements (EN/VN), and other business rules.

*   **Automated Workload Distribution:** Built mechanisms to route cases to the appropriate agents, specialists, or operational teams based on predefined assignment rules, ensuring balanced workloads and timely responses.

*   **Centralized Tracking System:** Created a unified tracking system using Microsoft Lists to monitor case ownership, status, SLA progress, follow-up activities, and completion outcomes in real-time.

*   **Shared Mailbox Integration:** Integrated with Outlook shared mailboxes to automatically generate and send standardized customer communications and internal notifications, ensuring consistency and reducing manual email drafting.

*   **End-to-End Status Management:** Developed exception handling and status management processes covering the entire case lifecycle: `Created`, `Follow-Up`, `Clearance`, `Picked`, `Unreached`, and other operational states.

*   **Enhanced Team Visibility:** Enabled real-time visibility of case queues and agent assignments, improving team coordination and workload management for supervisors.
